# 🧩 提示词写作模板与套路 · Templates

从本仓库 631 个案例中统计提炼（186 例显式声明画幅比例，358 例指定风格，75 例内嵌文案规格）。
以下 8 套框架覆盖全部案例的主要写法，可直接套用于 GPT-Image / Seedream / Nano Banana / Flux 等模型。

## 通用骨架（六槽位协议）

```text
【任务】生成一张 ____（媒介物：海报/截图/信息图/写真…）
【画幅】比例 9:16 竖版 / 16:9 横版，出血与留白说明
【主体】谁/什么，在做什么，穿什么，表情姿态
【场景】地点、时间、天气、背景元素层级（前景/中景/远景）
【风格】流派 + 光线（柔光/逆光/侧光）+ 质感（胶片/CCD/3D 渲染/等距）
【文字】需要渲染的中文文案逐字给出，并指定字体气质与位置
```

> 核心经验：**图内中文必须逐字写进提示词**，并单独成段标「正文的中文内容：」，否则模型会漏字/错字；
> 带标点的标题要在提示词中显式强调，否则常被丢字。

## 1. 社媒截图伪造（ui · ~40 例）

`画一张 X/微信/抖音 的界面截图 + 深色/浅色模式 + 账号名+认证标识 + 正文逐字 + 互动数字（点赞/转发）+ 评论区 2-3 条`。
关键是**逐区枚举 UI 零件**：头像、昵称、时间戳、九宫格、底部 tab。例：`例2、例184（杜甫朋友圈）、例234（朱元璋推特主页）`。

## 2. 信息图 / 知识可视化（infographic · ~82 例）

`垂直 9:16 等距剖面信息图「双语标题」` + 分区编号（01/02/03）+ 每区 `[图形+短标签]` + 图例与数据小表。
先给全图**标题文案**，再逐模块给文字，最后统一说明「所有中文必须正确渲染」。例：`例1 城市生命系统图谱`。

## 3. 海报版式（poster · ~112 例）

`主题海报 = 巨型主标题（位置+字体气质） + 副标题/日期/地点信息栏 + 单一强视觉主体 + 色彩系统（限定 2-3 色）`。
体育/电影海报套路：人物居中仰角 + 背景人群虚化 + 顶部片名底部演职员表。例：`例3 足球电影海报`。

## 4. 电商视觉（product · ~27 例）

`白底/场景底主图 + 3-4 张细节分镜（材质特写/使用场景/尺寸标注） + 卖点角标文案`。
亚马逊风：`A+ 页面模块化`；国潮风：米色纸纹底 + 书法字。例：`例178 亚马逊详情图`。

## 5. 品牌与 IP（brand · ~47 例）

`Logo：几何构成+网格规范+三色色卡`；`吉祥物：三视图（正/侧/背）+ 表情包九宫格 + 材质说明`。
一行品牌应用延展：名片/门头/包装贴图。

## 6. 摄影写实（photo · ~52 例）

`机型质感词（CCD 卡片机/徕卡/胶片 Portra） + 光线时段（日间清亮高光/黄昏逆光） + 镜头（35mm f/1.8 大光圈虚化） + 抓拍姿态`。
2025 后最热模板即 `例641-650 的 CCD 生活照` 系列：**先定「日间清亮高光」还是「冷白清透」，再给人物动作**。

## 7. 角色与卡牌（character · ~24 例）

`角色立绘 = 人设卡版式（名字/称号/属性数值栏） + 全身站姿 + 服饰装备枚举 + 背景纹样`；
卡牌合集 = 网格排列 N 张，每张统一边框。例：`十二黄金圣斗士卡牌合集`。

## 8. 视频提示词（video · ~27 例）

图生视频三段式：`首帧描述 + 镜头运动（推拉摇移/环绕/升格） + 主体动作与时序（0-2s…2-5s…） + 音效/氛围`。
示例见 `例541 草图→真实跑车`、`例542 旧房→高级住宅`（形态渐变类）。

---

## 反例与坑

- ❌ 只写「一张好看的海报」——没有文字槽位与版式指令，出图必平庸。
- ❌ 中文文案用「大意是…」转述——会被改写；必须**逐字引号给出**。
- ❌ 复杂版面不给编号——模型分不清模块；用 01/02/03 分块。
- ✅ 长提示词（中位数 ~1000 字）优于短句：本库高分案例全部是**枚举式长 prompt**。
